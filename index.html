CalendarMCP

CalendarMCP is a personal, self-hosted tool that runs on its owner's own Windows computer. It lets the owner's AI assistant (Claude) read and manage the owner's own Google and Outlook calendar appointments. It is not offered to the public.

Privacy policy

Last updated: 23 November 2026

  • What it accesses: calendar events and calendars of the Google accounts that the owner signs in with. It uses the scope https://www.googleapis.com/auth/calendar (full Google Calendar access): it reads, creates, changes and deletes events, lists calendars, and, only when the owner asks, creates new calendars (create_calendar) and deletes the owner's own secondary calendars (delete_calendar). Changes are only possible for accounts where the owner has turned writing on, and the primary calendar is never deleted. It does not access Gmail, contacts, Drive or any other Google data.
  • Where data goes: calendar data travels only between Google's API and the program on the owner's computer, and from there to the owner's AI assistant when the owner asks a question. There is no CalendarMCP server. Nothing is sent to the developer or to any third party, and nothing is sold or used for advertising.
  • Storage: CalendarMCP does not keep copies of calendar data. The OAuth refresh token and client secret are stored in Windows Credential Manager on the owner's computer, and never in plain-text files.
  • Revoking access: run calendar-mcp logout <account>, or remove the app at myaccount.google.com/permissions.
  • Google API Services User Data Policy: CalendarMCP's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Contact: the app's support email, as shown on Google's sign-in screen.
